# Dajet

Молчит в сеть. Говорит стилем.

**~6 MB** · macOS 14+ · WebKit · бесплатно

![Dajet browser](.github/screenshot.png)

---

## Что это

Чёрный экран. Строка ввода. Ничего больше.

Ты открываешь Dajet — чёрный экран. Вводишь адрес — ты на странице. Вводишь слова — ты ищешь. Вот и всё.

Нет часов. Нет даты. Нет виджетов. Нет "быстрых ссылок". Нет "рекомендаций". Нет ничего, что ты не попросил.

## Принцип

**Dajet — это экран, который ждёт тебя.** Не отвлекает. Не предлагает. Не советует.

Открой Network Monitor. Запусти Dajet. Ноль соединений. Без твоего действия — ничего не уходит в сеть.

- Нет телеметрии
- Нет аккаунтов
- Нет облака
- Нет рекламы
- Нет виджетов
- Нет "советов дня"

## Стартовый экран

Чёрный. Строка ввода. Всё.

Когда ты открываешь браузер или новую вкладку — ты видишь чёрный экран с одной строкой ввода по центру. Никаких часов. Никакой даты. Никаких виджетов. Ничего, что не попросил.

Строка ввода — умная. Подсказывает из твоей истории и закладок. Enter — и ты на странице или в поиске.

**Рендер мгновенный.** Ноль запросов. Ноль спиннеров. Ноль задержек.

Offline неотличим от online. В этом смысл.

## Когда ты на странице

Вот тогда появляется интерфейс:

- **Вкладки** — `⌘T` новая, `⌘W` закрыть, `⇧⌘[` `⇧⌘]` переключить
- **Закреплённые** — сожмутся до иконки
- **Split View** — две страницы рядом (`⌥⌘N`)
- **Блокировщик рекламы** — на уровне сети, до рендера
- **Скрой элемент навсегда** — `⇧⌘H`
- **Режим чтения** — `⇧⌘R`
- **Плавающее видео** — `⇧⌘P`
- **Пароли в macOS keychain**
- **Chrome-расширения** — (macOS 15.4+)
- **Обновления только по запросу**

Но стартовый экран — это не страница. Это пауза. Чёрная тишина перед действием.

## Privacy

| Что | Где | Кто может читать |
|---|---|---|
| Пароли | macOS login keychain | Dajet |
| История, закладки | `~/Library/Application Support/Dajet/` | Ты |
| Cookies | Store WebKit | Сайты |
| Всё остальное | Нигде | — |

Приватная вкладка (`⇧⌘N`) не оставляет ничего после закрытия.

## Установка

**Скачать:** [bro.dajet.ru](https://bro.dajet.ru)

**Собрать самому:**
```bash
git clone https://github.com/bestdeejay-design/dajet-browser
cd dajet-browser
swift build
```

macOS 14+, Xcode 16 / Swift 6.
