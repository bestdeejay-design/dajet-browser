# Dajet

Минималистичный браузер для macOS. Форк [Search](https://github.com/driceroland/Search) от Office Commun (MIT), переименованный и развиваемый дизайн-студией Dajet.

**~6 MB** · macOS 14+ · WebKit · бесплатно

![Dajet browser](.github/screenshot.png)

---

## Что это

Dajet — это браузер, который ничего от тебя не хочет. Нет телеметрии, нет аккаунтов, нет облака, нет рекламы. Нет стартовой страницы с "советами дня" и промо-плитками. Одна вкладка — одна страница. Одна строка адреса — один ввод. Всё.

Используется системный WebKit (тот же, что в Safari) — поэтому весь браузер весит ~6 мегабайт и открывается мгновенно. Нет второго Chromium в памяти, нет обновлений движка, нет зависимостей.

## Что умеет

- **Вкладки сверху или слева** — как хочешь, `⇧⌘S` переключить
- **Закреплённые вкладки** — сожмутся до иконки, не мешают
- **Split View** — две страницы рядом в одном окне
- **Блокировщик рекламы** — на уровне сети, до рендера
- **Скрой элемент навсегда** — `⇧⌘H`, кликни на cookie-баннер, он исчезнет и не появится при следующем визите
- **Режим чтения** — `⇧⌘R`
- **Плавающее видео** — `⇧⌘P`
- **Пароли в macOS keychain** — зашифровано системой, импорт из Chrome, Arc, Brave, Edge
- **Chrome-расширения** — вставь ссылку Chrome Web Store, работает (macOS 15.4+)
- **Обновления только по запросу** — ничего не проверяется само

## Чего нет и не будет

Намеренно:
- Телеметрия, аналитика, crash reports
- Аккаунты, облачная синхронизация
- Несколько окон (вкладки — единственный способ создать "новое")
- Промо-плитки, "советы дня", реклама
- Онлайн-виджеты

**Тишина — проверяемое заявление.** Открой Network Monitor, запусти Dajet — ноль соединений без твоего действия.

## Privacy

| Что | Где | Кто может читать |
|---|---|---|
| Пароли | macOS login keychain | Dajet |
| История, закладки | `~/Library/Application Support/Dajet/` | Ты |
| Cookies | Store WebKit | Сайты |
| Всё остальное | Нигде | — |

Приватная вкладка (`⇧⌘N`) не оставляет ничего после закрытия.

| | |
|---|---|
| `⌘L` адрес · `⌘T` новая · `⌘W` закрыть · `⌘K` список вкладок | `⌘[` `⌘]` назад/вперёд · `⇧⌘[` `⇧⌘]` предыдущая/следующая |

| `⌘F` найти · `⌘D` дублировать · `⇧⌘C` копировать адрес | `⌘Y` история · `⇧⌘J` загрузки · `⌘,` настройки |

## Установка

**Скачать:** [bro.dajet.ru](https://bro.dajet.ru) (когда будет готов signed build)

**Собрать самому:**
```bash
git clone https://github.com/bestdeejay-design/dajet-browser
cd dajet-browser
swift build
# или
./build.sh
```

macOS 14+, Xcode 16 / Swift 6.

Homebrew tap — с первым подписанным релизом.

## Для разработчиков

Исходники открыты. ~42 000 строк Swift, ноль зависимостей. Чтобы любой мог прочитать, что браузер делает с его паролями и историей. Собрать сам. Исправить то, что мешает.

- **SwiftUI** для UI, **AppKit** для title bar и dragging, **WKWebView** для страниц
- Один `Tab` на страницу, lazy loading — 20 вкладок = мгновенный запуск
- Блокировщик рекламы — `WKContentRuleList`, ноль стоимости во время выполнения
- `Sources/Dajet/` — один файл на concern: `Vault.swift` (keychain), `Shield.swift` (блокировщик), `Curtain.swift` (скрытые элементы), `Session.swift` (сессия), `Updater.swift` (обновления)

См. [CONTRIBUTING.md](CONTRIBUTING.md) и [SECURITY.md](SECURITY.md).

## Что дальше

Dajet — это форк Search 1.0.4, переименованный и с минимальными изменениями. Мы развиваем его в сторону:

- **Стартовый экран** — тема (обои + типографика), часы, дата как композиционный центр
- **Виджеты** — только локальные: календарь, напоминания, таймер, батарея, "сейчас играет"
- **Система тем** — manifest.json + wallpapers + theme.css, без кода
- **Бренд-темы** — как услуга студии

См. [ROADMAP.md](ROADMAP.md) и [docs/CONCEPT.md](docs/CONCEPT.md) (на русском).
