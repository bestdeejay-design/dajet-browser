Три кита

◯
Минимализм
В интерфейсе, в весе, в памяти. Всё, что можно убрать, убрано.
◉
Тишина
Ноль сетевых запросов без действия пользователя. Проверяемо — открой Network Monitor.
◈
Темы как искусство
Стартовый экран — галерея. Каждая тема — авторская работа с именем автора.

Что умеет

🔍
Одно поле
Адрес — ты на странице. Слова — поиск. Подсказки только из твоей истории.
📑
Вкладки, которые не мешают
Закрепи — сожмётся до иконки. Ленивая загрузка — 20 вкладок = мгновенный запуск.
⬜️
Split View
Две страницы рядом в одном окне. Двигай разделитель. Пары запоминаются.
🛡️
Блокировщик до рендера
Трекеры и реклама останавливаются на уровне сети — нечему рендериться.
🙈
Скрой навсегда
Cookie-баннер, newsletter, «похожее» — исчезает до того, как страница нарисовала фрейм.
🔐
Пароли в keychain
macOS keychain, зашифровано системой. Импорт из Chrome, Arc, Brave — в один клик.
🧩
Chrome-расширения
Без Chrome. Вставь ссылку Chrome Web Store — работает на WebKit, как Safari.
🎬
Видео идёт за тобой
⌘⇧P — видео вынимается из страницы в маленькое окно поверх всего.

Чего нет и не будет

  • Погода, новости, курсы валют на стартовом экране
  • AI-подсказки, «советы дня»
  • Аккаунты, облачная синхронизация
  • Телеметрия, аналитика, crash reports
  • Промо-плитки, платные места в быстрых ссылках
  • Онлайн-виджеты любой категории
Тишина — проверяемое заявление, а не обещание.
Открой Network Monitor, запусти Dajet — ноль соединений.

Privacy, конкретно

Что Где Кто может читать
Пароли macOS login keychain, обычные keychain items с тегом Dajet Dajet. Любое другое приложение вызывает системный диалог.
История, закладки, вкладки JSON в ~/Library/Application Support/Dajet/ Ты.
Cookies и данные сайтов Store WebKit для приложения Сайты, как в любом браузере.
Расширения ~/Library/Application Support/Dajet/Extensions/ Каждое расширение, в пределах принятых разрешений.
Всё остальное Нигде. Сервера нет. —
