Что это

Чёрный экран. Строка ввода. Ничего больше.

Ты открываешь Dajet — чёрный экран. Вводишь адрес — ты на странице. Вводишь слова — ты ищешь.

Нет часов. Нет даты. Нет виджетов. Нет "быстрых ссылок". Нет "рекомендаций". Нет ничего, что ты не попросил.

Принцип

Открой Network Monitor. Запусти Dajet. Ноль соединений.

Dajet занимает позицию, которую большие браузеры не могут скопировать: экран, который ждёт тебя. Не отвлекает. Не предлагает. Не советует.

Чего нет и не будет:
  • Часы, дата на стартовом экране
  • Виджеты любой категории
  • Погода, новости, курсы валют
  • AI-подсказки, "советы дня"
  • Аккаунты, облачная синхронизация
  • Телеметрия, аналитика, реклама
