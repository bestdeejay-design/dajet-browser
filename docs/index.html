Principle

Dajet holds a position big browsers cannot copy: a home that stays silent.

Open a network monitor. Launch Dajet. Zero connections.

Start screen

🌙
Dark by default
A soft dark field. No white noise. Light theme optional.
⌨️
One input line
Address or search. Suggestions from your history. Nothing extra.
⚡️
Instant render
No spinners. No “loading your config”. Ready at once.
🔇
Offline = online
Visually identical. That is the trick.

What is missing — on purpose

  • Weather, news, exchange rates on the start screen
  • AI suggestions, “tips of the day”, promo tiles
  • Accounts, cloud sync
  • Telemetry, analytics, crash reports
  • Online widgets of any category
This is not “not yet”. These are principled noes.
If any of this shows up — that is a bug, not a feature.

Themes

Every theme is an authored work. Like a poster. With the author’s name.

Format: manifest.json + wallpapers/ + theme.css + widgets.css. No code — designers don’t write JS.

The Dajet studio theme (“Dajet Quiet”) ships inside. Branded themes on commission — a studio service.

Open code

~42,000 lines of Swift, zero dependencies. So anyone can read exactly what the browser does with their passwords and history.
