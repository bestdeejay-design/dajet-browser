# Support

Dajet is a small project — the fastest way to get an answer is usually the docs.

## Where to start

- **README**: [README.md](README.md) — what Dajet is, its principles, features, and install instructions.
- **Design decisions**: [`docs/CHOICE.md`](docs/CHOICE.md) and [`docs/DEMOS.md`](docs/DEMOS.md) — why the start screen looks the way it does.
- **Signed releases**: [GitHub Releases](https://github.com/bestdeejay-design/dajet-browser/releases) — current version, DMG, and changelog; appcast lives at [`https://bro.dajet.ru`](https://bro.dajet.ru).

## Found a bug or want a feature?

Open an issue:

- [Bug report](https://github.com/bestdeejay-design/dajet-browser/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/bestdeejay-design/dajet-browser/issues/new?template=feature_request.yml)

Before opening a new issue, search the [existing ones](https://github.com/bestdeejay-design/dajet-browser/issues) — it may already be reported.

## Security

Security vulnerabilities are handled separately. See [`SECURITY.md`](SECURITY.md) — report privately, never in a public issue.
